## 後續驗證規則

1. 先用既有真牌事前資料離線回測，不直接部署。
2. 不增刪任何權重項目，只能調整比例。
3. 門檻不得降低；候選門檻須同時比較出手率、命中率與樣本數。
4. 不使用事後結果回填預測，不挑選有利樣本。
5. 和局、無預測及資料不完整須分開統計。
6. 只有在命中率提升且樣本量足夠時，才可提議實作下一版本。
